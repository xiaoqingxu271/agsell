这一版改了什么

  • 去掉插画与描边装饰，改用灰底 / 白卡两层结构拉开层级。
  • 品牌红只用于价格、CTA、选中态，其余文本回归黑灰，避免满屏红。
  • 商品流从不等高瀑布流改为定高双列卡，图 1:1、标题固定两行、价格行底部对齐。
  • 价格用等宽数字字体（¥ 11px / 整数 20px / 原价 11px 划线），数字对齐才显专业。
  • 标签体系收敛为 3 类语义：绿=服务承诺、红=促销、灰=属性，全部 1px 描边不用色块。
  • 秒杀改为标题+倒计时+横滑货架的独立模块，进度条承担紧迫感而不是靠大字报。
