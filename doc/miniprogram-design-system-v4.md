# agsell 小程序设计系统 v4.0（生鲜电商标准版）

> 适用范围：**小程序端** `agsell-uniapp`（uni-app + Vue 3，编译为微信小程序）。
> 生效日期：2026-09-18 · 本文档为小程序端页面样式**唯一权威来源**，取代 `miniprogram-design-system-v3.md`。
> 设计稿：`doc/design-v4/`，共 21 张高保真图（1080×2280），与 `pages.json` 21 个页面一一对应。
> 设计基准：京东 APP / 盒马鲜生 / 拼多多 已被验证的成熟电商范式——用户零学习成本，转化优先。
> 约束：所有色值、字号、间距、圆角必须走 token（`uni.scss`），禁止页面内散写裸色值。

---

## 0. 设计判定（Design Read）

定位：**面向 C 端的生鲜电商小程序**，商业感强、信息密度适中、转化路径短。

三旋钮：`DESIGN_VARIANCE: 3`（成熟电商=秩序与熟悉感）· `MOTION_INTENSITY: 3`（按压/加载 100–200ms 轻反馈）· `VISUAL_DENSITY: 5`（每屏 3–5 个信息块，不拥挤不空荡）。

---

## 1. 设计原则

1. **绿色主品牌，红色促转化**：明亮生鲜绿 `#00B578` 承载品牌与主操作；红色 `#E63946` 严格只用于价格、促销标签、未读角标——**不允许红、绿之外出现第三种强调色**。
2. **布局有层次**：通栏头图/导航 → 白色内容卡片 → 卡片内分区，三层结构；卡片之间用浅灰底分隔，不靠描边。
3. **重点突出**：价格永远是页面内视觉权重最高的元素（红色、大号、粗体）；主 CTA 永远在底部固定操作栏，绿色实心，占据屏幕宽度 40% 以上。
4. **交互即时反馈**：所有可点元素有按压态（透明度 0.85 或深色叠加）；选中态用实心填充+对勾；未读用红色小圆点/数字角标。
5. **组件复用**：`ProductCard`、`NavBar`、`StarRating`、`AddressPicker`、底部操作栏 `AppFooter` 全局复用，改 token 即全局生效。
6. **触控硬约束**：主按钮高度 ≥ 88rpx；可点元素热区 ≥ 64rpx；相邻可点元素间距 ≥ 16rpx。

## 5. 组件规范

### 5.1 按钮

| 类型 | 背景 | 文字 | 高度 | 圆角 | 用途 |
|---|---|---|---|---|---|
| 主按钮（绿） | `#00B578` | 白 28rpx/600 | 88rpx | 44rpx | 提交订单、确认支付、发表评价 |
| 主按钮（红） | `linear-gradient(#E63946,#FF6B35)` | 白 28rpx/600 | 88rpx | 44rpx | 立即购买、立即秒杀、结算 |
| 次要按钮 | 白底 + 1rpx `#00B578` 边 | `#00B578` | 80rpx | 40rpx | 加入购物车、查看订单 |
| 文字按钮 | 透明 | `#9CA3AF` 或 `#E63946` | 64rpx | 0 | 删除、取消 |
| 圆形加购 | `#00B578` | 白 + | 56rpx | 50% | 商品卡右下角快速加购 |

> 按压态：`opacity: 0.85`，过渡 150ms。

### 5.2 卡片

- 页面左右边距 24rpx，卡片之间垂直间距 16rpx。
- 卡片白底细圆角 24rpx + `$shadow-sm`；**禁止**卡片描绿边（v3 已废除）。
- 卡片内边距 24rpx。

### 5.3 商品卡（双列流）

- 宽度 = `(100vw - 24×3 rpx) / 2`，白底圆角 24rpx。
- 上半部分商品图 1:1，圆角 16rpx。
- 下半部分：商品名一行（28rpx，超出省略）→ 价格红色 32rpx/700 + 划线原价灰色 24rpx → 右下角圆形加购按钮。

### 5.4 价格展示

- 列表/卡片：`¥` 符号 24rpx + 数字 32rpx/700，红色 `#E63946`。
- 详情页：`¥` 28rpx + 数字 56rpx/700，红色。
- 划线原价：灰色 `#9CA3AF`，删除线，24rpx。

### 5.5 TabBar（全局底部）

- 白底，顶部 1rpx `#E5E7EB` 分隔线。
- 图标 48rpx，未选 `#9CA3AF`，选中 `#00B578`。
- 五个 tab：首页 / 分类 / 购物车 / 消息 / 我的。购物车右上角红色角标 `#E63946` 白字。

### 5.6 顶部导航栏

- 非首页：白底，黑色标题 34rpx/600，左侧返回箭头。
- 首页：通栏绿底 `#00B578`，白色文字 + 白色搜索框（圆角胶囊，内 `#F3F4F6` 占位）。
- 秒杀页：通栏红底 `#E63946`，白字。

### 5.7 状态标签

- 圆角胶囊，高度 40rpx，左右 padding 16rpx，字号 22rpx。
- 配色按 §2.5 语义色表。
- 必须「颜色 + 文字」双通道，不允许只用颜色表达状态。

### 5.8 表单

- 输入框：白底圆角 16rpx，高 80rpx，padding 0 24rpx，边框 `#E5E7EB`。
- 聚焦：边框变 `#00B578`，无外发光。
- 多选标签（规格/原因）：选中 = 绿底白字；未选 = 灰底 `#F3F4F6` 黑字。

| 秒杀 | 橙红渐变卡 | 整屏红头通栏 | 秒杀两页重写 |

## 8. 落地顺序建议

1. **改 token**：`src/uni.scss` 按 §2–§4 替换变量。
2. **改全局**：`App.vue` 背景、`pages.json` navigationBar/tabBar 色值。
3. **改 tab 页**：首页 01 → 分类 05 → 购物车 03 → 我的 04（用户最高频）。
4. **改交易链**：商品详情 02 → 购物车 03 → 确认 09 → 收银台 21 → 支付成功 10。
5. **改次级页**：订单/售后/评价/搜索/AI客服/秒杀/溯源。
6. **验证**：每页对照 `doc/design-v4/` 同名 PNG 走查色值、圆角、按钮状态。
