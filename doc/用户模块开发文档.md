## 1. 模块概述

### 1.1 模块定位

用户模块是 agsell 系统的基础认证与用户管理中心，承担以下核心职责：

- **用户身份认证**：微信小程序授权登录（code → openid → JWT）
- **用户信息管理**：注册、登录、个人信息修改、头像更新
- **收货地址管理**：地址的增删改查、默认地址设置
- **管理员认证**：后台管理端的账号密码登录与鉴权
- **权限拦截**：通过 JWT 拦截器校验请求合法性，将用户身份注入 ThreadLocal

### 1.2 与其他模块的关系

```
┌──────────────────────────────────────────────────────┐
│                   用户模块                            │
│  ┌─────────────┐    ┌─────────────┐                 │
│  │  小程序用户  │    │  后台管理员  │                 │
│  │  (sys_user) │    │ (sys_admin) │                 │
│  └──────┬──────┘    └──────┬──────┘                 │
│         │                  │                         │
│         └────────┬─────────┘                         │
│                  ▼                                    │
│         JWT 拦截器 + ThreadLocal                      │
│         (注入当前用户ID / 管理员ID)                    │
└──────────┬───────────────────────────────────────────┘
           │ 共享 BaseContext.getCurrentId()
    ┌──────┼────────────────┐
    ▼      ▼                ▼
  订单    购物车           评价
  模块    模块            模块
```

用户模块为订单、购物车、评价等模块提供用户身份上下文（`BaseContext.getCurrentId()`），是本系统所有业务模块的前置依赖。

### 3.2 认证流程

#### 小程序用户登录流程

```
小程序端                              后端
   │                                   │
   │  1. wx.login() → code             │
   │  2. POST /api/user/login          │
   │     { "code": "xxx" }             │
   │  ──────────────────────────────>  │
   │                                   │  3. 调用微信接口换取 openid
   │                                   │  4. 查询 sys_user，若不存在则自动注册
   │                                   │  5. 生成 JWT（含 userId，有效期 7 天）
   │                                   │  6. 更新 login_ip、login_time
   │  <──────────────────────────────  │
   │  7. { "token": "eyJ...", ... }    │
   │  8. 存入 wx.setStorageSync        │
   │                                   │
```

#### 管理员登录流程

```
管理端                              后端
   │                                │
   │  1. POST /api/admin/login      │
   │     { "username": "admin",     │
   │       "password": "xxx" }      │
   │  ───────────────────────────>  │
   │                                │  2. 查询 sys_admin
   │                                │  3. BCrypt 密码比对
   │                                │  4. 校验 status（是否禁用）
   │                                │  5. 生成 JWT（含 adminId + role）
   │                                │  6. 更新 login_ip、login_time
   │  <──────────────────────────── │
   │  7. { "token": "eyJ...",       │
   │       "adminInfo": {...} }     │
   │  8. 存入 localStorage          │
   │                                │
```

### 3.3 JWT 拦截器设计

拦截器在请求进入 Controller 之前执行，流程如下：

```
请求到达
   │
   ▼
┌──────────────────────┐
│ 检查请求路径是否白名单 │  ← /api/user/login、/api/user/register 等无需登录
└──────────┬───────────┘
           │ 需要登录
           ▼
┌──────────────────────┐
│ 从请求头提取 Token    │  ← Authorization: Bearer xxx
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ JwtUtils.parseToken() │  ← 验证签名、过期时间
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 设置 BaseContext      │  ← BaseContext.setCurrentId(userId)
└──────────┬───────────┘
           │
           ▼
     继续请求 → Controller
           │
           ▼
┌──────────────────────┐
│ finally: 清理 ThreadLocal │ ← BaseContext.removeCurrentId()
└──────────────────────┘
```

```sql
-- 用户模块建表
CREATE TABLE IF NOT EXISTS `sys_user` (
    `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    `username`    VARCHAR(50)  NOT NULL COMMENT '登录用户名（手机号）',
    `password`    VARCHAR(255) NOT NULL COMMENT '加密密码（BCrypt）',
    `nickname`    VARCHAR(50)  DEFAULT NULL COMMENT '昵称',
    `avatar`      VARCHAR(255) DEFAULT NULL COMMENT '头像URL',
    `phone`       VARCHAR(20)  DEFAULT NULL COMMENT '手机号',
    `openid`      VARCHAR(100) DEFAULT NULL COMMENT '微信小程序openid',
    `status`      TINYINT      NOT NULL DEFAULT 1 COMMENT '状态 0=禁用 1=正常',
    `login_ip`    VARCHAR(50)  DEFAULT NULL COMMENT '最后登录IP',
    `login_time`  DATETIME     DEFAULT NULL COMMENT '最后登录时间',
    `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `deleted`     TINYINT      NOT NULL DEFAULT 0 COMMENT '软删除标记',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_username` (`username`),
    KEY `idx_openid` (`openid`),
    KEY `idx_phone` (`phone`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';

CREATE TABLE IF NOT EXISTS `sys_admin` (
    `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    `username`    VARCHAR(50)  NOT NULL COMMENT '登录用户名',
    `password`    VARCHAR(255) NOT NULL COMMENT '加密密码（BCrypt）',
    `real_name`   VARCHAR(50)  DEFAULT NULL COMMENT '真实姓名',
    `role`        VARCHAR(20)  NOT NULL DEFAULT 'ADMIN' COMMENT '角色 ADMIN/OPERATOR',
    `status`      TINYINT      NOT NULL DEFAULT 1 COMMENT '状态 0=禁用 1=正常',
    `login_ip`    VARCHAR(50)  DEFAULT NULL COMMENT '最后登录IP',
    `login_time`  DATETIME     DEFAULT NULL COMMENT '最后登录时间',
    `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `deleted`     TINYINT      NOT NULL DEFAULT 0 COMMENT '软删除标记',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='管理员表';

CREATE TABLE IF NOT EXISTS `user_address` (
    `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    `user_id`     BIGINT       NOT NULL COMMENT '用户ID',
    `receiver`    VARCHAR(50)  NOT NULL COMMENT '收件人姓名',
    `phone`       VARCHAR(20)  NOT NULL COMMENT '手机号',
    `province`    VARCHAR(50)  NOT NULL COMMENT '省',
    `city`        VARCHAR(50)  NOT NULL COMMENT '市',
    `district`    VARCHAR(50)  NOT NULL COMMENT '区/县',
    `detail`      VARCHAR(255) NOT NULL COMMENT '详细地址',
    `is_default`  TINYINT      NOT NULL DEFAULT 0 COMMENT '是否默认地址 0=否 1=是',
    `tag`         VARCHAR(20)  DEFAULT NULL COMMENT '标签 家/公司/学校',
    `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME     DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `deleted`     TINYINT      NOT NULL DEFAULT 0 COMMENT '软删除标记',
    PRIMARY KEY (`id`),
    KEY `idx_user_id` (`user_id`),
    UNIQUE KEY `uk_user_default` (`user_id`, `is_default`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户收货地址表';
```

```java
@Service
@RequiredArgsConstructor
public class UserServiceImpl extends ServiceImpl<SysUserMapper, SysUser> implements UserService {

    private final JwtUtils jwtUtils;

    @Override
    @Transactional
    public UserLoginVO login(UserLoginRequest request) {
        // 1. 调用微信接口获取 openid
        String openid = wechatService.openid(request.getCode());

        // 2. 查询用户
        SysUser user = lambdaQuery()
                .eq(SysUser::getOpenid, openid)
                .one();

        // 3. 自动注册（首次登录）
        if (user == null) {
            user = new SysUser();
            user.setOpenid(openid);
            user.setUsername(generateUsername(openid));
            user.setPassword(""); // 微信登录用户无密码
            user.setStatus(1);
            save(user);
        }

        // 4. 校验状态
        ThrowUtils.throwIf(user.getStatus() == 0, ErrorCode.NO_AUTH_ERROR, "账号已被禁用");

        // 5. 更新登录信息
        user.setLoginIp(ClientUtils.getIp());
        user.setLoginTime(LocalDateTime.now());
        updateById(user);

        // 6. 生成 token
        String token = jwtUtils.generateToken(user.getId());

        // 7. 构建响应
        UserLoginVO vo = new UserLoginVO();
        vo.setToken(token);
        vo.setUserId(user.getId());
        vo.setNickname(user.getNickname());
        vo.setAvatar(user.getAvatar());
        vo.setPhone(user.getPhone());
        return vo;
    }

    @Override
    public UserInfoVO getUserInfo() {
        Long userId = BaseContext.getCurrentId();
        SysUser user = getById(userId);
        ThrowUtils.throwIf(user == null, ErrorCode.NOT_FOUND_ERROR, "用户不存在");

        UserInfoVO vo = new UserInfoVO();
        BeanUtils.copyProperties(user, vo);
        vo.setHasPhone(StrUtil.isNotBlank(user.getPhone()));
        return vo;
    }

    @Override
    @Transactional
    public void updateUserInfo(UserUpdateRequest request) {
        Long userId = BaseContext.getCurrentId();
        SysUser user = new SysUser();
        user.setId(userId);
        BeanUtils.copyProperties(request, user);
        updateById(user);
    }
}
```

### 7.2 UserAddressServiceImpl 实现要点

```java
@Service
@RequiredArgsConstructor
public class UserAddressServiceImpl extends ServiceImpl<SysUserAddressMapper, SysUserAddress>
        implements UserAddressService {

    @Override
    public List<UserAddressVO> listAddresses() {
        Long userId = BaseContext.getCurrentId();
        List<SysUserAddress> list = lambdaQuery()
                .eq(SysUserAddress::getUserId, userId)
                .orderByDesc(SysUserAddress::getIsDefault)
                .orderByDesc(SysUserAddress::getCreateTime)
                .list();
        return list.stream().map(this::convertToVO).collect(Collectors.toList());
    }

    @Override
    @Transactional
    public void addAddress(UserAddressDTO dto) {
        Long userId = BaseContext.getCurrentId();

        // 若设为默认地址，先清除其他默认
        if (Boolean.TRUE.equals(dto.getIsDefault())) {
            lambdaUpdate()
                    .eq(SysUserAddress::getUserId, userId)
                    .set(SysUserAddress::getIsDefault, 0)
                    .update();
        }

        SysUserAddress address = new SysUserAddress();
        BeanUtils.copyProperties(dto, address);
        address.setUserId(userId);
        save(address);
    }

    @Override
    @Transactional
    public void updateAddress(UserAddressDTO dto) {
        Long userId = BaseContext.getCurrentId();

        SysUserAddress address = lambdaQuery()
                .eq(SysUserAddress::getId, dto.getId())
                .eq(SysUserAddress::getUserId, userId)
                .one();
        ThrowUtils.throwIf(address == null, ErrorCode.NOT_FOUND_ERROR, "地址不存在");

        // 若设为默认，清除其他默认
        if (Boolean.TRUE.equals(dto.getIsDefault())) {
            lambdaUpdate()
                    .eq(SysUserAddress::getUserId, userId)
                    .ne(SysUserAddress::getId, dto.getId())
                    .set(SysUserAddress::getIsDefault, 0)
                    .update();
        }

        SysUserAddress update = new SysUserAddress();
        BeanUtils.copyProperties(dto, update);
        update.setUserId(userId);
        updateById(update);
    }

    @Override
    public void deleteAddress(Long id) {
        Long userId = BaseContext.getCurrentId();
        boolean exists = lambdaQuery()
                .eq(SysUserAddress::getId, id)
                .eq(SysUserAddress::getUserId, userId)
                .exists();
        ThrowUtils.throwIf(!exists, ErrorCode.NOT_FOUND_ERROR, "地址不存在");
        removeById(id);
    }

    @Override
    @Transactional
    public void setDefaultAddress(Long id) {
        Long userId = BaseContext.getCurrentId();

        // 先清除所有默认
        lambdaUpdate()
                .eq(SysUserAddress::getUserId, userId)
                .set(SysUserAddress::getIsDefault, 0)
                .update();

        // 再设置目标为默认
        lambdaUpdate()
                .eq(SysUserAddress::getId, id)
                .eq(SysUserAddress::getUserId, userId)
                .set(SysUserAddress::getIsDefault, 1)
                .update();
    }
}
```

```java
        SysAdmin admin = adminMapper.selectOne(
                new LambdaQueryWrapper<SysAdmin>()
                        .eq(SysAdmin::getUsername, request.getUsername())
        );
        ThrowUtils.throwIf(admin == null, ErrorCode.NOT_FOUND_ERROR, "用户名或密码错误");

        // 2. 密码校验
        ThrowUtils.throwIf(
                !BCrypt.checkpw(request.getPassword(), admin.getPassword()),
                ErrorCode.NOT_FOUND_ERROR, "用户名或密码错误"
        );

        // 3. 状态校验
        ThrowUtils.throwIf(admin.getStatus() == 0, ErrorCode.NO_AUTH_ERROR, "账号已被禁用");

        // 4. 更新登录信息
        admin.setLoginIp(ClientUtils.getIp());
        admin.setLoginTime(LocalDateTime.now());
        adminMapper.updateById(admin);

        // 5. 生成 token（需扩展 JwtUtils 支持管理员）
        String token = jwtUtils.generateAdminToken(admin.getId(), admin.getRole());

        // 6. 构建响应
        AdminLoginVO vo = new AdminLoginVO();
        vo.setToken(token);
        vo.setAdminId(admin.getId());
        vo.setRealName(admin.getRealName());
        vo.setRole(admin.getRole());
        return vo;
    }

    @Override
    public AdminLoginVO getAdminInfo() {
        Long adminId = AdminContext.getCurrentAdminId(); // 需新建 AdminContext
        SysAdmin admin = adminMapper.selectById(adminId);
        ThrowUtils.throwIf(admin == null, ErrorCode.NOT_FOUND_ERROR, "管理员不存在");

        AdminLoginVO vo = new AdminLoginVO();
        vo.setAdminId(admin.getId());
        vo.setRealName(admin.getRealName());
        vo.setRole(admin.getRole());
        return vo;
    }
}
```

### 8.3 拦截器设计

```java
@Component
public class JwtAuthInterceptor implements HandlerInterceptor {

    @Value("${jwt.token-header}")
    private String tokenHeader;

    @Value("${jwt.token-prefix}")
    private String tokenPrefix;

    @Autowired
    private JwtUtils jwtUtils;

    // 白名单：无需登录的接口
    private static final List<String> WHITE_LIST = List.of(
            "/api/user/login",
            "/api/user/register",
            "/api/user/logout",
            "/api/admin/login"
    );

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        String uri = request.getRequestURI();

        // 白名单直接放行
        if (WHITE_LIST.stream().anyMatch(uri::endsWith)) {
            return true;
        }

        // 提取 token
        String token = request.getHeader(tokenHeader);
        if (token == null || !token.startsWith(tokenPrefix + " ")) {
            throw new BusinessException(ErrorCode.NOT_LOGIN_ERROR);
        }

        token = token.substring(tokenPrefix.length() + 1);

        try {
            Long userId = jwtUtils.getUserId(token);
            BaseContext.setCurrentId(userId);

            // 解析 token 中的 type，区分用户和管理员
            Claims claims = jwtUtils.parseToken(token);
            String type = claims.get("type", String.class);
            if ("admin".equals(type)) {
                AdminContext.setCurrentAdminId(
                        Long.valueOf(claims.getSubject()),
                        claims.get("role", String.class)
                );
            }
            return true;
        } catch (Exception e) {
            throw new BusinessException(ErrorCode.NOT_LOGIN_ERROR);
        }
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response,
                                Object handler, Exception ex) {
        BaseContext.removeCurrentId();
        AdminContext.removeCurrentAdminId();
    }
}
```

#### 安全增强：JWT + Redis Token 管理
- **问题**：原 JWT 无状态设计，logout 仅前端删 token，后端无法撤销
- **方案**：JWT（签名+时效）+ Redis（白名单）= 可控的无状态认证
- **实现**：
  - `JwtUtils` 生成 token 时加入 `jti`（UUID）
  - 新增 `RedisTokenService` 接口 + `RedisTokenServiceImpl` 实现
  - `JwtAuthInterceptor` 校验时查 Redis 验证 token 有效性
  - `BaseContext` / `AdminContext` 存储 jti，logout 时删除 Redis 中的 token
  - 新增 `POST /api/admin/logout` 接口
- **白名单调整**：`/api/user/logout` 和 `/api/admin/logout` 从白名单移除，需要认证
