## 0. 设计判定（Design Read）

> Reading this as: **premium C-end commerce**（面向消费者的高级电商体验），with a **premium enterprise language** — deep emerald brand + neutral slate surfaces, quiet elevation, restrained motion。与管理端 v3.0「企业级运营控制台」同语言、同节奏，双端一品牌。

三旋钮（design-taste-frontend 约定）：`DESIGN_VARIANCE: 5`（企业级=克制与秩序）· `MOTION_INTENSITY: 4`（120–200ms 轻动效）· `VISUAL_DENSITY: 5`（信息清晰、不拥挤）。

## 1. 设计原则（企业级铁律，小程序版）

1. **中性为底，品牌点睛**：页面/卡片大面积中性灰白，品牌绿只用于关键时刻——主按钮、激活态、导航栏、状态渐变、重点数据（价格/评分）。禁止每张卡片都描绿边。
2. **层级清晰的排版**：页面标题 36rpx/600 → 卡片标题 32rpx/600 → 区块标题 30rpx/600 → 正文 28rpx/400 → 辅助 22–24rpx；数字一律 `tabular-nums` 对齐。
3. **触控优先（硬约束）**：主操作按钮 ≥ 88rpx（44px）；卡片内次要操作 ≥ 64rpx；相邻可点元素间距 ≥ 16rpx；全部可点元素带按压反馈。
4. **克制动效**：按压/聚焦/显隐 120–200ms `ease-out`；无冗余弹跳与无限动画；`prefers-reduced-motion` 全量降级为 0ms/仅透明度。
5. **可访问性优先**：正文对比度 ≥ 4.5:1（对照 §2.6 已测色表）、状态标签「颜色 + 文字」双通道、图标按钮带 `aria-label`/文本、装饰图标 `aria-hidden`。
6. **组件复用**：导航栏 `NavBar`、商品卡 `ProductCard`、评分 `StarRating`、地址弹层 `AddressPicker`、输入 `InputEntry`、底部操作 `AppFooter` 全部复用；全局 token 只落在 `uni.scss` + `App.vue` 两处，禁止页面内散写裸色值。

### 2.5 品牌绿渐变（小程序 signature move）

品牌记忆点：**所有关键头部与状态区使用品牌绿渐变**（管理端对应深翡翠侧栏渐变，小程序端取更通透的品牌绿区间）。
> v3.1（2026-09-09 反馈提亮）：渐变整体从「深翡翠 `#0E3B25/#0A2A1B`」提亮为「品牌绿 `#15803D/#16A34A`」区间，保留层次与高级感，观感更通透。

| 场景 | 渐变 |
|---|---|
| 自定义导航栏 `NavBar` | `linear-gradient(180deg, #15803D 0%, #14532D 100%)` |
| 首页搜索区 / 我的页用户头部 | `linear-gradient(160deg, #15803D 0%, #166534 100%)` |
| 订单详情状态卡 / 售后详情状态区 | `linear-gradient(135deg, #15803D 0%, #14532D 100%)` |
| banner 占位图 | `linear-gradient(135deg, #15803D 0%, #14532D 100%)` |
| 卡片标题左侧竖条 | `linear-gradient(180deg, #22C55E 0%, #15803D 100%)` |

> 线性渐变 GPU 合成免费；径向/多段渐变禁止（Android 低端性能预算，见 §9）。渐变上白字对比度下限：两端与中央均 ≥5.0:1（已按「白字/白辅助字」实测，见 §2.6）。

### 2.6 对比度实测表（v3 关键新增，其余沿用 MASTER §2.6）

| 色对 | 对比度 | 用途 | 判定 |
|---|---|---|---|
| `#FFFFFF` / `#15803D` | 5.02:1 | 品牌绿渐变浅端白字 | ✅ |
| `#FFFFFF` / `#166534` | 7.12:1 | 渐变深端（搜索区/我的页）白字 | ✅ |
| `#FFFFFF` / `#14532D` | 9.05:1 | 渐变深端（状态卡/banner/导航）白字 | ✅ |
| `#FFFFFF` / 渐变中央 | ≥ 5.9:1 | 渐变中央白字（最弱点：搜索区/我的页 `#15803D→#166534` 中央 ≈ 6.0:1；状态卡 `#15803D→#14532D` 中央 ≈ 6.7:1） | ✅ |
| `#6B7280` / `#F4F6F5` | 4.4:1 | **禁止**页面底直接文字，改 `#4B5563` | ⚠️ 受限 |
| `#4B5563` / `#F4F6F5` | 6.87:1 | 页面底直接文字 | ✅ |
| `#6B7280` / `#FFFFFF` | 4.83:1 | 白卡内次要文字 | ✅ |
| `#A16207` / `#FFFFFF` | 4.92:1 | 价格文字 | ✅ |
| `#1F2937` / `#F4F6F5` | 13.7:1 | 页面底正文 | ✅ |

> 结论：实心状态按钮一律品牌绿 `#15803D`；小号状态一律**浅底深字标签**；卡片边界靠「1px 中性描边 + 分层阴影」识别，不再单独依赖 1.21:1 的绿描边。

| Token | 时长 | 场景 |

## 9. 响应式、安全区与性能

1. **rpx 自适应**：全部尺寸 rpx（750 设计稿）。
2. **宽屏居中**（平板/H5 宽窗）：`@media (min-width: 1000px)` 下页面根容器与底部固定栏 `max-width: 900px; margin: 0 auto`（用 **CSS px**，rpx 随视口缩放无法做真正的平板约束）。
3. **安全区**：底部固定元素统一 `env(safe-area-inset-bottom)`；375px 小屏与 iPhone 底部小黑条必须验证。
4. **触控反馈**：卡片/按钮 `hover-class` 或 `:active` 按压缩放（H5 生效 `:active`；微信端用 `hover-class`）。
5. **性能预算**：
   - 渐变只用 ≤3 段线性渐变（GPU 免费）；禁止多段径向渐变。
   - 卡片阴影仅 1–2 层，禁止大范围 `backdrop-filter` 堆叠。
   - 商品图全部 `lazy-load`；轮播 `autoplay` 保留手滑（可暂停）。
   - 动画只动 `transform` / `opacity`，不动 `width`/`top`。
