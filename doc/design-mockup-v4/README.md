## 1. 设计原则（三维度）

### 1.1 布局：层次感 + 重点突出
1. **浅色侧栏 + 分组导航**：白底侧栏，菜单按「运营 / 内容 / 系统」分组，激活项主色浅底 + 左指示条，视觉轻盈聚焦内容。
2. **指标带主卡制**：销售总额为主卡（渐变 + 金色强调、占比大），其余 4 项次卡等宽，一眼抓重点。
3. **主次分明的图表区**：趋势主图宽幅（8 列），构成次图 2×2（各 6 列），层级清晰。
4. **工具条紧凑化**：搜索区从"整块搜索卡"改为紧凑工具条，给表格让出空间；页面 24px 网格留白。

### 1.2 配色：统一 + 和谐 + 符合场景
1. **青翠绿 × 丰收金 × 中性底**：保留品牌绿色相并提亮为"生机绿"，丰收金用于金额/评分，中性底 95% 承载内容。
2. **颜色即语义**：状态色固定（success/warning/danger/info + 金 accent），标签一律浅底深字双通道。
3. **图表与界面同色板**：图表系列色 = 界面色板，绿起头、金强调、蓝扩展。

### 1.3 交互：及时反馈
1. **加载**：表格骨架屏、图表 loading 遮罩。
2. **悬停**：卡片抬升（shadow + 上移）、行高亮、操作列浮现、图标按钮底色。
3. **操作**：按钮按压层级、提交 loading、成功/失败顶部 toast、乐观更新。
4. **空态**：插画 + 文案 + 引导按钮。
